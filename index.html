01   VERSTEHEN

Eine kleine Maschine für Zahlen

Eine Funktion erhält einen Wert, verarbeitet ihn und gibt ein Ergebnis zurück. Das Schlüsselwort return schickt diesen Wert an die aufrufende Stelle.

function plusEins(zahl) {
  return zahl + 1;
}

plusEins(4); // Ergebnis: 5

zahl ist ein Parameter: ein Name für die Eingabe. Du kannst mit ihm rechnen wie mit einer gewöhnlichen Zahl.

Deine Aufgabe

Verdopple die Eingabe zahl und gib das Ergebnis zurück. Schreibe nur den Funktionskörper. Verwende den Operator * zum Multiplizieren.

Beispiele: 3 → 6 und −4 → −8.

Ein kleiner Hinweis

Nach return steht dein Rechenausdruck. Ein Semikolon beendet die Anweisung. Die Eingabe mit zwei zu multiplizieren funktioniert auch für null und negative Zahlen.
